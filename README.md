# Design folder

Content calendar: `Content_Calendar.xlsx` in this folder, one tab per brand. Update it as we work.

Everything is under `brands/`. Each brand has the same layout, so the same thing is always in the same place.

| Folder | What is in it |
|---|---|
| `brief.md`, `crit.md` | What the brand is, and notes from each design review |
| `research/` | References and point of view |
| `final/` | Illustrator masters and the images they use. Do not move or rename `final/assets/` |
| `exports/` | PDFs and packs to share |
| `social/` | Instagram: one master file and ready-to-post images |
| `explorations/` | Build scripts |
